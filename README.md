# Tuesday 24 November 2026: 38 date-checked stories, 6 regions, 14 drawn

One image that sums up the world's news of Tuesday 24 November 2026, ranked
by consequence. Lead story: three oil tankers hit naval mines in the Strait
of Hormuz (IRGC claim, reported 24 Nov). Also leading: the Oxfam–CEOBS
report that Gaza is a "toxic wasteland" (99% of the territory showing
contamination indicators), and Trump's Justice Dept death-penalty directive
against Gov. Newsom's plan to commute 548 death-row sentences.

The page carries 38 date-checked stories across 6 regions, 14 flat-drawn
illustrations, a numbered-pin world map, a "THE DAY IN NUMBERS" strip, a
"STORIES BY REGION" bar, a "HOW SURE" legend, a "THE DAY IN UTC" timeline,
and a DATE CHECK footer that lists the stories deliberately LEFT OUT because
they belong to other days (Nvidia's Huang reinstatement, the Delta outage,
the US measles ruling, and more).

## How it works

`entry.png` (1024×1024, 187,527 bytes) was rendered locally in the builder
session and is shipped in this repository. `main.py` uses only the Python
standard library: it verifies the shipped file (PNG magic bytes, size,
SHA-256, 1 MiB gate) and copies it byte-for-byte to `/output/entry.png`.
Two runs write the same bytes. No network is used.

## Run it

```sh
python3 main.py   # writes /output/entry.png
```
